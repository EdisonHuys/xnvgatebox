# 首次使用：从登录到客户端上网

**不需要先把全部候选测完，也不需要手动新增入站。** 建议先用本机直出验证客户端，再按需要添加 VPN Gate 或自有代理；已有就绪出口时可直接从第 3 步导入订阅。

1. **登录管理页。** 使用安装完成时显示的地址和密码；忘记地址时在 VPS 执行 `xnvgatebox access`。总览仅保留「设置出口 → 等待就绪 → 复制订阅 → 导入使用」四步。
2. **建议先启用一个基础连接。** 在「出口管理 → VPS 本机直出」点击「启用」。此入口使用服务器公网 IP，可在没有 VPN Gate 节点时验证客户端接入；它是可选项，不会成为其他出口的故障备用。
3. **把订阅添加到客户端。** 在「我的订阅」点击「复制订阅链接」。在 v2rayN 等支持 VLESS / REALITY 的客户端新建订阅分组、粘贴订阅地址并更新订阅；选择 `VPS 本机直出`（或已就绪出口），启用客户端的系统代理或相应代理模式，再访问网页验证。服务器防火墙须允许管理页显示的实际**接入端口**，只开放 8899 管理端口不足以连接代理。重装系统后须使用新订阅地址。
4. **添加 VPN Gate 出口。** 在「出口管理 → 调整 VPN Gate 数量」填写需要的目标数量，首次未保存时预填 4；已有数量和明确保存的 0 均保留。国家可留空。程序自动寻找候选、连接，并创建和绑定对应的 VLESS / REALITY 接入入口；等待出口显示「已就绪」，再在客户端更新原订阅、手动选择该出口。数量由使用者决定，实际受主机资源、地址/端口及上游供给限制；目标数量不保证当时全部就绪。国家查询失败或证据过期时，指定国家的策略可能等待；国家不限且允许 unknown 可继续验证连通，仍不能据此称为家宽。
5. **有自己的固定代理时再添加。** 在「代理资源 → 第三方 SOCKS5」填写地址、端口、账号密码，可选国家、城市与备注；保存后检测，确认「启用」与「加入订阅」已开启，再更新客户端订阅。可在「我的订阅」单独选自有代理，也可与其他来源一起使用；客户端显示用户备注，供应商原始凭据留在 VPS。见 [第三方代理说明](THIRD_PARTY_SOCKS.md)。
6. **其他资源按需使用。** 「候选节点」用于刷新来源、单条或批量检测及排障，不是订阅的前置步骤。「代理资源 → VPS SOCKS5」供其他电脑或程序通过本 VPS 接入，需显式开启外部端口；「原始 SSTP」导出给支持 SSTP 的客户端，自身不是可直接导入 v2rayN 的 VLESS 订阅。普通使用无需进入「接入管理」新增入口；自行新增的入口须绑定已有出口，未绑定时阻断流量。

### 页面状态怎样看

| 页面或提示 | 含义与下一步 |
| --- | --- |
| 候选「检测通过」 | 表示那次临时连接通过；15 分钟内的观察会优先用于新出口选点，正式连接仍重新验活。不会把每个候选自动变成常驻出口。配置变化后排序提示失效。 |
| 出口「连接中 / 等待候选」 | 当前还不能提供该出口的订阅连接，等待就绪或查看检测原因；不需要反复新建入站。 |
| 出口「已就绪」 | 当前连接已经通过运行验活，可更新客户端订阅获取入口；不保证上游永久在线。 |
| 「地区未知」或 unknown | 国家或类型缺少可信证据，与当前连通状态分开判断；「地区未知」且「已就绪」可以同时出现，不能称为已验证家宽。 |
| 订阅选项变灰 | 勾选「全选」时单项由全选控制；取消相应全选后可逐个选择。VPN Gate 实际只输出已就绪入口。 |
| 新建入站「未绑定」 | 只有客户端接入配置，没有出口，连接会阻断；新增时可选择已有出口，等待或停止的出口也能预先绑定。只有该出口就绪后才可通行。 |

订阅默认按本机直出 → 自定义代理 → VPN Gate 排列；客户端需主动更新订阅获取变化，再手动选择使用的节点。VPN Gate 和自定义代理故障时阻断，不自动切换本机直出。指定国家暂时没有合适 IP 时保留策略等待，不强求国家或出口数量。

「候选节点」的检测与正式 OpenVPN 建连共享「检测与建连并发数」；恢复连接优先，等待名额显示等待，已有稳定隧道不占建连名额。调低后让进行中的任务完成，不强断连接；配置很高仍需主机资源支持。

「接入管理」以列表展示自动入口、手动入口和本机直出，可配置或启停。自动入口由出口数量维护，删除对应出口后才可清理入口；手动入口可直接删除。停用入口保留端口与凭据。普通使用无需手动新增。

国家使用实测出口 IP 查询，默认通过正常 HTTPS 请求 [country.is](https://country.is/) 并严格比对返回 IP，缓存一天；失败短暂退避，缺失时显示地区未知。`COUNTRY_URL_TEMPLATE` 可在私有 `intelligence.env` 中替换兼容 JSON 服务（含 `{ip}`）或设空关闭；不向国家服务发送画像密钥。国家证据不证明住宅属性，未配置可信分类服务时类型仍为 unknown。
