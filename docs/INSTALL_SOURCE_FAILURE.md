# 安装与候选来源分离

2026-10-24 开发约定：安装程序先于 VPN Gate 节点筛选。VPS 连接官方来源超时、来源返回异常或没有可解析候选时，仍可安装并登录后台；本机直出与第三方 SOCKS5 由用户明确启用和配置后独立使用。VPN Gate 不可用时对应出口等待、连接阻断，不自动切换来源或回落直出，不把 unknown 视为住宅。

## 行为

- 安装仍验证依赖、完整包 SHA256、文件清单、配置、服务健康，沿用锁、备份和恢复。
- Pool Builder 用专用非零退出码区分上游候选不可用与配置、文件系统或程序故障。后者仍阻止部署，不能假装安装成功。
- 来源不可用且有旧有效候选池时保留；没有旧池时不生成虚假的清单、更新时间或可用节点，安装结果明确提示“VPN Gate 候选暂不可用”。
- 源码配置错误、损坏旧清单及安装故障继续报错和保留现场。
- 安装终端逐阶段显示进度；后台未取得候选清单时说明可先使用直出或自定义 SOCKS5，并可刷新来源。定时器继续按原计划重试。
- 源恢复后通过原 Pool Builder 原子更新清单，管理器读取真实候选；候选本身仍需验活。

## 验证计划

Python 回归覆盖无池新装、无池重复更新、旧池保留、非来源错误拒绝、损坏池拒绝和失败恢复。六系统容器增加受控不可达 HTTPS 来源的新装及更新，验证实际直出订阅 HTTPS、不自动启用直出、不伪造候选和网络恢复后的清单刷新。正常联网测试保留。容器结果不替代真实 VPS 的网络、SELinux/firewalld 或真实 VPN Gate 正向连接；第三方 SOCKS5 功能沿用已有独立链路并回归。本轮不连接用户 VPS、不开 CF、不改 3x-ui。
