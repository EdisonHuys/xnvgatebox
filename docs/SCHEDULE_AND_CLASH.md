# 周期任务与 Clash 订阅

## 设置周期

打开「候选节点 → 周期任务」，分别设置「自动刷新来源」和「自动检测候选」。两项默认开启、间隔 60 分钟，最低 30 分钟，也可分别关闭。检测沿用当前并发；不建议为了缩短等待而对志愿者节点频繁重试。

自动任务不叠加，按完成时间计算下一轮；同时到期先刷新再检测。刷新失败保留旧池，已有候选仍可检测；正在使用的出口继续独立健康检查，不因批量检测重拨或回落直出。页面显示上次结果和下次时间，正在运行时显示完成后再计时。

周期设置和运行时间持久化，重启保留既有时间；首次无池可做一次初始化获取。手动刷新和检测保留，并更新对应执行时间；网页刷新及 `xnvgatebox refresh` 不受自动开关和间隔限制。Go 管理器负责调度，系统定时器仅做受同一到期规则约束的后备触发，不能绕过关闭开关或间隔限制。手动任务优先，不重叠全池任务；关闭周期只停止后续自动启动，当前检测可使用已有取消按钮。原始 SSTP 的周期设置独立保留。

## 导入 Clash Verge

在「我的订阅」选择「Clash Verge / Rev（Mihomo）」格式，再复制订阅链接，在客户端添加远程配置并更新。使用支持 VLESS/REALITY 的 Mihomo 内核。v2rayN 保持默认格式；之前复制的 Base64 链接不会自动变为 Clash 配置。

Clash 输出是完整配置，支持本项目生成的 VLESS、VMess、Trojan 的 TCP、WebSocket、gRPC，以及 VLESS/REALITY。使用未支持的传输时明确拒绝导出。原订阅的令牌、范围、名称、顺序和就绪校验保持一致。转换在本 VPS 内完成，不把订阅或密钥发送给第三方转换服务。

没有就绪入口时返回非成功状态，不生成假节点。不自动加入 DIRECT 后备，不降低证书验证，不把 unknown 标为住宅。用户仍可主动选择订阅内已开启的「VPS 本机直出」，它是通过 VPS 接入的独立节点。

## 验证范围

用固定官方 Mihomo v1.19.33 验证生成配置和本机直出真实链路，包括 HTTPS 出口、内容及代理故障时阻断；GUI 版本未给出，不把内核验证称为所有 Clash Verge 版本均兼容。定时测试使用受控时钟与临时目录，不等待真实小时，也不向 VPN Gate 压测。所有构建与真实 VPN 验收分开记录，CF 暂停、3x-ui 不改。
