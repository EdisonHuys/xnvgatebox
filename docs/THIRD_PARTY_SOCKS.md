# 第三方 SOCKS5：手动资源与订阅

2026-10-18 需求已对齐，本文先于实现记录本轮范围。GitHub Actions 自动检测/公开发布继续暂缓；CF 保持暂停，不修改 3x-ui。

## 输入和管理

“代理资源”增加“第三方 SOCKS5”页签。手动填写服务器域名/IP、端口、账号、密码、国家、城市、备注；国家/城市/备注选填。提供新增、编辑、删除、启停、独立的加入订阅开关及真实检测。本期不接代理商 API、不自动购买、不创建供应商会话或轮换地址。

每条资源拥有稳定的内置 VLESS/REALITY 入站及独立 SOCKS 出站；编辑上游、地理标注和备注不更换入站端口、UUID 或 REALITY 密钥。连接为客户端 → 本 VPS → 第三方 SOCKS5 → 目标，不依赖 VPN Gate 隧道，仍需 VPS 在线。停止/删除/上游失败时不可回落本机直出、VPN Gate 或其他代理。

供应商凭据仅保存于本机私有状态，资源列表不返回密码，登录后的编辑接口才可读取；不进入客户端订阅、普通状态、日志或 GitHub。管理接口沿用登录和来源校验及 no-store。内置配置变更复用现有校验、事务和回滚；整份 Xray 重启可能短暂影响连接。

## 地区、备注和检测

国家、城市可手填；检测获取实际公网出口、HTTPS 延迟/内容及独立画像。手填值、实测值分开保存，不一致明确提示；画像服务未配置/失败、城市缺失或过期如实待验证，不能凭供应商或手填认定住宅。unknown 不称家宽。备注永不被检测覆盖。

订阅名使用新鲜可信实测地区；无实测时使用带“手动标注”的手填地区；没有地区则“地区待验证”。无备注例：`🇺🇸 美国 · 洛杉矶 · 第三方 · 01`；有备注例：`🇺🇸 美国 · 洛杉矶 · nov proxy-los`。系统分类始终为第三方 SOCKS5，备注只替换默认名称。原 VPN Gate 名称加来源标识，保留用户自定义部分。重复名自动避让。

本期针对固定代理，以 SOCKS5 远程 DNS 连接完成两个独立 HTTPS IP 回显一致及 HTTPS 内容验证，正常验证目标证书。地址/认证变化后旧检测失效，编辑地区/备注保持连接证据但不伪造地区证据。检测异步、可见运行和终态，同项去重；停服取消并等待结束。固定代理检测到出口变化明确记录，不把历史 IP 当成当前实际 IP。本期不承诺轮换代理、多次请求固定出口或未经实测的 UDP 能力。

## 订阅范围

“我的订阅”按 VPN Gate、第三方 SOCKS5、VPS 本机直出分组；前两组支持全选（含今后新增）和逐项选择，直出独立选择。第三方还须启用且允许加入订阅。保留旧订阅默认范围及参数含义：旧 `slots=` 仍只选指定 VPN Gate；新增第三方筛选必须支持全选、排除、指定 ID 和仅第三方；链接、明文复制及二维码使用相同范围。全空仍返回非 200，避免客户端被空订阅清空。

## 验收

验证真实固定认证 SOCKS5 → 内置加密入口 → 订阅客户端的两次准确出口和 HTTPS 内容；错误密码、上游停止、资源停止/删除均失败且不回落，其他资源独立。验证重启/编辑/事务失败后的凭据和路由、备注/手填与实测地区/失效证据、分类范围/二维码/无凭据泄露及已有 VPN Gate/直出回归。真实付费代理由用户私有提供；若未提供，只能声明受控 SOCKS5 链路验收，不能称已验收购买的住宅代理。部署遵循既有完整备份和配置保留流程，不强求上游国家和数量。
