# 默认出口与候选刷新

2026-10-24 开发约定：内置模式尚未设置出口数量、没有已有 Slot 时，在取得有效候选后自动保存 16 个 VPN Gate 出口目标，并创建、绑定和尝试连接，不再要求先打开数量表单。首次没有候选时等待，不将未检测候选作为可用出口发布。

默认策略与原数量表单一致，不限国家和类型，unknown 只代表未分类。已有数量（含明确的 0）、端口、凭据、策略和无计划的旧 Slot 保留；旧 Slot 不自动扩容。非内置后端不启用本默认。管理员容量不足 16 时明确提示并等待调整，不静默降低目标。

手动刷新、定时获取和服务重启读取已有池都能触发初始化。刷新成功信号唤醒后台对账，避免等待下一轮轮询；重复信号不重复创建，停止服务时不再初始化。仍使用原有建连并发，16 个目标不表示同时建立 16 个连接，不强求上游提供 16 个可用节点，不自动切换本机直出。

验证覆盖无池等待、首次有池自动出现 16 个入口、重复刷新与重启身份保留、保存 0 后不自动恢复、旧数量和旧 Slot 保留、容量限制、绑定失败重试，以及真实完整包的受控清单刷新和更新保留。合成候选测试不计为真实 VPN 连通。
