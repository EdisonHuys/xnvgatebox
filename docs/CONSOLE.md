## VPS 本机直出与外部 SOCKS5（2026-10-18 已部署开发版）

总览可独立启停“VPS 本机直出”，启用后原默认订阅即包含 `VPS 本机直出`，客户端刷新订阅即可获取；可在“我的订阅”排除直出，或只选择直出。仅此明确入口走服务器网络，不计入 VPN Gate 目标数量；未绑定、等待、失败、停止或删除的 VPN Gate 出口继续阻断，不自动切换本机直出。现有绑定、端口、凭据和策略不改变。

在“接入管理 → SOCKS 凭据”开启“允许其他电脑或 Worker 接入”并保存，即分配独立的外部 TCP 端口；原内部 SOCKS 保持本机监听。外部入口沿用对应 Slot 的账号密码、固定身份和真实隧道，换节点后地址不变；停止/故障时阻断，不回落直出。关闭外部接入保留端口，重新开启不重置凭据。未开启时显示本机地址，不再伪装成公网可用链接。外部端口须允许通过用户防火墙。SOCKS5 不需要域名证书，协议自身不加密。

已开启且就绪的 SOCKS5 链接可在登录管理面后，从 `GET /api/console/socks` 私有导出，用于其他电脑或未来 Worker 的私有配置。它不是匿名公开清单，不自动上传 GitHub。检测通过的原始 VPN Gate IP 不等于 SOCKS5 服务；这些外部入口由 VPS 持续维持隧道。CF 当前仍暂停，本轮只验证外部 SOCKS，不宣称 Worker 端到端已验收。自动申请 TLS 证书暂缓。

订阅范围参数：默认输出已就绪 VPN Gate 入口及已启用的本机直出；`direct=0` 排除直出，`slots=1,2` 延续原行为只选这些 VPN Gate 出口（如需加直出，再加 `direct=1`），`vpn=0&direct=1` 只选直出。二维码与复制地址保持相同范围。外部 SOCKS 不混入 VLESS 聚合订阅。所有私有链接和凭据应只通过私有方式分享。

## 统一检测与自定数量（2026-10-18）

用户只需“检测”，不区分候选与出口的实现方式。两者统一报告实际出网结果、实际 IP、可信国家、延迟、阶段和时间；已有连接复用，未连接候选临时验证。预检通过不能直接标记可用。

检测并发用数字输入并保存，允许 64、128 等用户选择；批量范围由勾选或“全部”决定。目标出口数移除固定 32 上限。默认值可以保守，但不能用测试机配置限制其他安装，也不静默改小用户设置。实际清单数量继续按上游返回展示。后台网络地址与身份按需分配，旧身份和凭据兼容保留；真实端口、地址空间或系统分配失败须明确显示原因，不承诺无限资源或上游必有节点。

单行按钮点击立即进入提交状态，防止重复点击；手动检测优先，可与批量任务共存。实际开始后按钮与行内同步显示旋转圆环及阶段，等待则如实显示等待，完成显示结果。批量并发为用户配置的总额度，手动优先使用空闲额度或在下一次额度释放时优先开始；不为手动操作额外超出用户额度。统一取消等待全部资源清理，重启清理所有本实例诊断残留。并发配置保存在私有 `check-settings.json`，重启保留；运行中修改并保存时用于下一轮任务，当前任务显示自己实际使用的并发。

## 使用

- 出口总览：分别查看目标、就绪、等待、停止与来源候选数量；主机内存只是资源参考。
- 出口管理：自由设置非负整数目标数量（管理员可通过 `-max` 自定实例容量），程序为新增出口自动建立 VLESS/TCP/REALITY 入站。默认保留现有出口策略，新国家条件只用于新增出口。数量不再限制为 32；资源和上游供给决定实际就绪数，分配失败明确提示。
- 我的订阅：默认包含全部就绪且启用的内置入站，并包含今后新增的出口；也可选择编号生成固定范围订阅。复制原链接到客户端，刷新订阅同步数量和名称。等待或停止的出口暂不输出；如果范围内没有就绪入站，返回非 200，让客户端保留上次配置。保留的旧节点在服务端仍受到阻断保护。
- 候选节点：搜索、按来源国家及检测状态筛选，单行、勾选或全部检测；并发数自由输入并保存。手动检测优先，行内和按钮同步显示旋转圆环及阶段。候选列表不是“已验证可用列表”，完整返回当次来源清单，不截断为 200 项。
- 设置：管理密码、路径和端口；“高级设置 → 接入管理”入口集中管理协议、端口、客户端及导出；原 `/advanced` 地址仍可访问新版页面，顶部不显示内部二进制路径。登录页与控制台使用统一配色，支持深浅主题和手机布局、密码显示切换及登录错误反馈。默认浅色，可切换深色。顶部仅使用 xnvgatebox 品牌，开源致谢及许可继续保留。

“新增接入入口”是为客户端增加一套协议、监听端口与凭据，不会增加独立出口。创建后从入口的“配置 → 出口”选择已有的就绪出口；未绑定时继续阻断。日常设置出口数量会自动建立默认接入入口。

改变数量保留已存在出口的端口与凭据。减少数量从最大编号开始移除；对应内置入站留存并显式阻断，再增加相同编号时复用其端口及客户端密钥。移除后重新创建的 SOCKS 认证属于新 Slot 生命周期，可能重新生成。数量计划写入私有 `console.json`，重启恢复计划，故障后重试尚未完成的分配或绑定。

国家没有合适 IP 是上游供给或可达性条件，不要求某国随时成功。等待出口保留策略和编号，绝不跨国凑数或直连母机。类型缺少证据时如实显示 unknown，不能称为家宽。

## 名称和二维码

自动名称来自当前已核验 OpenVPN 实际出口国家，例如 `🇯🇵 日本 · 01`；同国家换 IP 不改变这个名称。缺少可信国家时显示“待验证”。同一出口有多个入站/客户端时追加区分字段；可在出口管理中切换自定义名称。名称通过真实订阅链接的 fragment 输出，不只是管理页装饰。旧安装尚未保存命名方式的 `slot-01`–`slot-32` 默认名也按自动命名处理；显式保存的自定义方式和其他手动备注保持不变。接入管理中只改端口或启停状态时，会保留所选命名方式。

二维码由本机管理服务生成，不调用外部二维码网站；生成接口也需要管理员登录。订阅口令和二维码均属于私有访问凭据。

## 刷新与检测的区别

“刷新候选池”触发 VPS 上同一个 Python Pool Builder 从官方来源重新采集，成功后重读清单；失败保留旧清单并报告失败。使用与定时器一致的文件锁，已有任务运行时不会并发覆盖。列表数量是完整解析官方本次公开响应后的候选数，不等于 VPN Gate 全球服务器总数；会随时间变化。

“检测当前出口”使用现有 SOCKS 对两个 HTTPS Echo 做实际出口核验，检查结果必须一致且等于该出口记录；不重启健康隧道。发现出口变化会阻断，避免回落母机。

已经作为运行出口的候选复用现有 SOCKS 检测，避免对同一上游重复拨号影响现有会话。其他“检测候选节点”在独立临时 namespace 建立真实 OpenVPN，再通过独立 SOCKS 核验两个 HTTPS Echo，匹配基线、画像和 actual IP。它不是 ping 或 TCP 端口测试。临时诊断使用独立的负数身份，正式出口使用正数身份，不共用编号。诊断并发按用户配置执行，运行出口复用检测也计入同一检测额度；正式出口的后台建连仍另有两个并发名额。对同一节点或同一服务器 IP 的临时检测与正式出口拨号互斥；正式出口需要该节点或网段时，先取消临时检测并等待清理，再继续恢复。已被其他出口用于建连的候选显示“稍后再测”，不会重复拨号。取消后清理临时连接、namespace、监听和私有临时文件，不把未完成结果写成成功。

检测会先对简单的 TCP 配置做快速端口预检，总预算 6 秒、单地址最多 2 秒；UDP、域名及复杂配置直接交给完整验证，不用 TCP 结果推断。预检成功不会产生“通过”结果，仍须完成独立出口与实际 SOCKS 核验。

检测展示排队、预检、临时连接、上游建连、隧道出口、画像、实际出口核验和清理阶段，正在检测的项目优先展示。无需先测完全部候选才能使用订阅，正式出口建立时仍独立验活。检测展示进度、时间和失败原因。15 分钟后或来源 OpenVPN 配置变化时，旧诊断结果标记过期；历史成功不代表节点现在一定可用，正式出口建立时仍重新验活。服务停止时取消检测和刷新并等待清理；异常退出后，启动时根据创建网络前写入的私有资源记录，核对并清理本实例所有诊断环境，再恢复正式出口；兼容旧版 240/241 诊断清理。残留进程须同时匹配 OpenVPN、私有检测配置路径及 namespace，使用 pidfd 固定进程身份后才结束。检测记录 `checks.json` 只是辅助观察，不能在重启后恢复 healthy 状态。

实例当前拥有一个独立 `/16`，可分配 16,384 条 `/30` 网络链路。这是实际地址空间约束，正式出口与诊断共享空闲链路，不代表机器承载能力。原有 1–255 编号保持原地址，大编号使用原先空闲的 `/30`，旧 Slot 端口、凭据和绑定不变。并发输入 64/128 有效，未设置时默认 2；没有按机器内存静默改小的逻辑。地址耗尽、固定端口越界或端口占用须报告；管理员自行设置的 `-max` 继续有效。默认值不等于固定产品上限。

停服时先等待正在提交的状态写入结束，再禁止后台保存，最后关闭运行连接；临时关闭不能保存为用户主动停止。已保存的主动停止意图继续保留。

内置 Xray 的入站/路由配置变更仍可能整体重启 Xray，短暂中断其他客户端连接；纯检测和无变化的数量对账不触发此操作。CF 保持暂停，测试与安装只操作本项目。

## 代理资源（2026-10-18 已部署开发版）

左侧“代理资源”集中管理两种连接：

- **VPS SOCKS5**：查看现有出口、内部端口与独立外部端口，启停外部接入、查看/复制账号和私有导出；修改凭据可直达该出口的接入管理。连接依赖 VPS 与对应隧道在线。
- **原始 SSTP**：复用官方候选池，按来源国家、搜索词和结果筛选；单条检测可以优先加入现有任务，支持勾选/全部、取消与阶段进度。并发、周期（0 关闭）、有效期和超时可保存；运行中修改用于下一轮，不改变原有 OpenVPN 检测并发或目标出口数。

原始 SSTP 经 VPS 临时隔离拨号，验证正常证书、PPP、两处 HTTPS 出口 IP 及 HTTPS 内容。来源地区与实际国家分开；没有独立画像证据仍为 unknown。检测结束即释放连接，不创建常驻代理。过期、候选变化或未完整通过的节点不会进入有效导出；CF 始终显示待验证，本轮不恢复 CF。

私有 JSON 标识 `kind: vpngate_vps_sstp_observations`、VPS 观测与有效期；文本是 SSTP 连接参数，需支持 SSTP 的消费端使用，不是 v2rayN 的 VLESS 订阅。VPS 可承担抓取、周期检测及清单生成，未来 Worker 仍需要自己的实测与同步适配。本轮不自动上传 GitHub，不公开匿名 SSTP 清单。

部署与验收见 [代理资源记录](PROXY_RESOURCES.md#本轮验收记录) 和 [脱敏证据](evidence/vps-sstp-resources-20261018.json)。周期检测默认关闭，当前保存并发 16、有效期 60 分钟、单节点超时 90 秒；这些值由用户调整，不作为所有 VPS 的统一容量。
