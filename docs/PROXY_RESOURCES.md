# 代理资源：本地 SSTP 检测与清单导出

2026-10-18 开发约定先于实现单独提交，现已完成开发与授权 VPS 部署（干净包 `5daca26`）。验收范围与保留的失败见文末及 [脱敏证据](evidence/vps-sstp-resources-20261018.json)。

## 界面与职责

独立“代理资源”菜单，两个页签：

- VPS SOCKS5：管理已有 Slot 的内部/外部端口、启停外部访问、查看/复制凭据及私有导出。仍依赖 VPS 常驻，沿用原 Slot 身份、账号和路由，不另建出口。
- 原始 SSTP：复用唯一官方 Pool Builder 的候选，不另抓取、不截断清单；展示来源地区、候选端口、实际出口、VPS 检测阶段/结果、延迟、检测时间、失效时间与失败原因。支持搜索/国家筛选、单个/勾选/全部检测、取消、用户保存并发、手动优先和重复请求去重。

原始 SSTP 不计入 VPN Gate 目标出口数，不要求先启动 OpenVPN Slot。端口来自候选推导，只能视为待测，TCP/TLS 或握手成功均不足以标为出网通过。VPS 画像不可沿用 OpenVPN 的国家/ISP/家宽证据，缺失保持 unknown；来源国家和实测国家分开显示。界面不误称 CF 已可用。

## VPS 本地检测

连接实际 SSTP → PPP/IP 地址协商 → 两个独立 HTTPS 回显一致 → HTTPS 内容验证。实际出口须为合法公网 IPv4 且不能是 VPS 本机直出；延迟来自真实 HTTPS 请求。使用正常证书验证，不照搬旧 Worker 的 TLS 身份认证技术债。SSTP 服务证书必须正常验证；不因候选普遍证书失败而自动绕过。

优先复用系统维护的 SSTP/PPP 客户端和已有 Linux 网络隔离机制，避免自写简化 TCP 协议栈。依赖随安装入口检查和准备；依赖缺失须明确报错，不伪造结果。临时网卡 MTU 适配实际上游链路，避免默认 1500 高于 VPS 上游导致 TLS 大包停滞。检测放在本实例拥有的临时网络环境中，不修改母机默认路由、不触碰 3x-ui，不占用持久 Slot；正式出口恢复优先。取消/超时/停服清理全部所属进程和资源；异常退出后先清理本实例残留再恢复，不能误杀其他 VPN/PPP。并发数字由用户决定，实际资源不足明确报告，不静默降低。临时检测不能成为长期代理端口。

## 结果、调度与导出

私有结果与设置独立落盘，包含候选摘要、验证环境 VPS、协议 SSTP、检查时间、有效期和失败码；不在公共报告保存连接口令。候选端点或配置变化、超过有效期、缺证据均排除出有效导出；取消/排队不能覆盖旧完成记录，旧结果不得恢复为常驻连接。

单条、勾选和全部有效节点支持复制/下载文本 SSTP 连接信息及结构化 JSON。JSON 包含主机名、检测所用 server_ip 与端口，明确 schema、验证来源/时间、有效期和 CF 未验证，不伪装为旧 mode_a_validated/cf_manifest 的全链路证据。导出受管理登录保护，Cache-Control no-store；凭据仅出现在明确私有导出，不自动上传 GitHub、不公开匿名订阅。

支持保存可关闭的周期检测间隔，由 VPS 抓取/检测/生成清单替代 GitHub Actions 的节点维护任务；与现有来源刷新共用唯一池。首版安装不自动开始全池扫描。定时检测与手动任务共用调度，避免重叠；运行中保存新并发用于下一轮。关闭服务后原始清单使用是否独立取决于消费端是否已保存有效快照；未来 CF 必须另做其运行环境的实测、失效阻断和快照同步，本轮不部署或写入 CF。

## 验收

先完成确定性回归：协议边界、候选变化/过期过滤、来源与实测国家区分、有效导出与登录保护、并发/优先/去重/取消、重启保留和故障清理；检查 JS、构建、真实 Xray 配置及已有出口回归。浏览器使用虚构凭据验证两个页签、状态和导出范围，真实测试私有保存。

授权 VPS 备份后部署，保留原目标数、原端口/客户端/SOCKS 凭据、策略、用户检测并发、管理设置和订阅口令；3x-ui 原进程与运行配置保留。真实 SSTP 正向、TLS 错误拒绝、取消/异常恢复及原有公开订阅复验分别报告；上游无合适节点时如实记“上游条件不足”，不能把未测当成功，不强求国家或数量。CF 始终暂停，unknown 不称家宽。


## 本轮验收记录

- 真实首轮使用用户已保存的 16 并发检查全部 98 个候选，57 个完成正常证书、SSTP/PPP、两处准确 HTTPS 出口及 HTTPS 内容验证。另起任务实测优先加入、去重、阻止重叠和取消：16 个实际运行、95 项取消，旧完成证据保留，临时资源清理。最终重启快照含 54 个有效结果，CF 全部待验证；新完成的失败观测允许替换旧成功结果。
- 设置与结果私有保存、单条/全部有效导出、选择范围、空范围拒绝、登录保护及 no-store 通过；最终 JSON 保留检测用 `server_ip`。原始文本是连接参数，消费端需要支持 SSTP，不是 VLESS 订阅。
- 239 个 Linux 顶层用例 / 295 个通过事件与 64 项 Python 通过，包含真实隔离客户端、超时清理、非 443 控制端口残留恢复及母机路由/PPP 文件不变。最终 GitHub 全部检查与新增 SSTP/周期调度 race 通过。周期任务的关闭、到期启动、不重叠、间隔未到不重启通过确定性测试；线上留为关闭。
- 16 项升级保留检查与最终 13 项复核通过。完整一致性备份及后续含 SSTP 结果的备份均保存 VPS/Mac；原 32 目标、16 检测并发、管理/订阅口令、端口、客户端/SOCKS 凭据、策略与开关保留，3x-ui 原进程和运行配置相同。正常停服/升级重启保留 SSTP 结果，未恢复为常驻连接。
- VPS/Mac 实测原默认订阅、独立本机直出、原 Slot 2 VLESS 和外部认证 SOCKS，要求两处准确 IP 与 HTTPS 内容，错误 SOCKS 密码拒绝。Slot 1/3 当时上游条件不足，保留策略等待；未强迫跨国，不宣称全部 32 目标均已实测。

保留的实现失败：测试 VPS 上游 MTU 1400，而临时网卡默认为 1500，导致 TLS 停滞；隔离对照中同一 HTTPS 请求在 1500 超时、1400 通过，已修复自动适配。另两个单候选分别在 HTTPS 内容与 IP 回显阶段失败，没有当作通过导出。首轮 CI 的全量 321 次持久写入超过测试的三秒等待，已调整为等待任务完成（最长 30 秒），数量断言保留，最终检查全绿。客户端误用不存在路径及实际传输重试记录也保留；未绕过证书或出口一致性校验。CF 未写入、部署或实测，unknown 未称为家宽。
