# Debian 12 全新安装与完整包在线更新

v0.6.2 安装与更新规范（2026-10-19）。固定版本安装命令见 README；使用者已重装 Debian 12 并报告安装成功；已只读观察到候选通过与出口就绪，完整客户端验收仍需另行记录。

## 本轮范围

将已验收控制台、可自定出口/并发、默认订阅直出、外部 SOCKS5、原始 SSTP 管理同步到默认分支和正式完整安装包。统一安装、命令行更新、网页在线更新使用同一完整包，不只替换管理器二进制。CF 继续暂停，不修改 3x-ui，不把 unknown 称为家宽。

系统采用 Debian 12 amd64、systemd；Ubuntu 保留支持说明，未实测的系统不称为已验收。操作系统由用户自行重装，本项目不执行重装或磁盘清除。

## 安装与升级约定

- 下载固定发布标签对应完整包与 SHA256，检查归档路径、类型、重复项、文件清单和每个成员摘要；失败不替换现有部署。只有本项目官方 GitHub 发布资产作为默认来源。
- 同一台主机只运行一项部署。网页任务通过独立 systemd 单元执行，不受管理进程重启影响；重启前后可查询持久进度。命令行和网页共用安装入口与部署锁。
- 下载、依赖及候选池预备尽量在原服务运行时完成。升级时停止本项目候选刷新和管理服务，创建一致的完整私有项目备份，再检查旧状态和替换完整程序、Python 工具、Xray 与服务文件。
- 保留管理路径/密码/端口、订阅口令、Slot 身份/凭据/策略/启停、接入配置、直出/外部 SOCKS 设置、检测并发和 SSTP 设置/结果；原有配置不套用新安装默认值。
- 通过本地登录与管理 API 检查实际运行版本。安装或健康检查失败时恢复本项目备份和原服务状态；恢复失败保留恢复记录、报告需要处理，不宣称成功。未完成部署在下次操作时先恢复。备份仅覆盖本项目受管文件，不是操作系统镜像，不回滚系统依赖包。
- 服务状态快照先查询 systemd LoadState，尚不存在的项目 unit 记为未运行/未启用，不执行会产生误导报错的 is-enabled 查询；systemd/bus 查询失败仍报错并停止安装，不能伪记为已停用。
- 新系统首次安装创建独立随机访问路径、管理密码与订阅凭据；默认不强制启动固定数量出口，不自动开启全量协议检测。首次操作见 [首页逐步说明](../README.md#首次使用从登录到客户端上网)：建议启用本机直出验证接入，再导入客户端订阅、设置出口数量并等待就绪；候选全量检测与手动新增入站均非前置；无画像服务时国家/类型证据缺失保持未知，固定国家策略可等待。

## 用户入口

README 的一键命令在安装成功后自动执行 `xnvgatebox access`，直接显示本机私有管理地址和初始密码。首次安装生成独立随机路径、密码和订阅凭据；该查看命令不重置凭据，已有更新保留原值。`xnvgatebox version` 查看安装版本，`xnvgatebox check-update` 检查正式更新，`xnvgatebox update` 更新完整部署；网页“设置 → 版本与更新”提供检查、执行及进度。旧 v0.4.0 网页尚无完整升级能力，首次迁移使用新版一键安装入口。

完整安装命令、首次登录与更新操作已同步到 [README](../README.md) 和 [VPS 文档](../vps/README.md)。本机已有完整私有备份保留，重装后第一次验收不导入旧状态，以免把迁移当全新安装。

## 全新系统验收清单

1. 用户重装 Debian 12 amd64，核实新的 SSH 主机指纹，再以 root 执行 README 的固定版本安装命令；不关闭 SSH 主机身份检查。
2. 确认 `xnvgatebox version` 为 v0.6.2，管理服务及候选刷新定时器正常；执行 `xnvgatebox access`，开放实际管理端口后登录。
3. 不导入旧备份，确认生成了新的私有路径、管理密码与订阅；启用 VPS 本机直出，在 v2rayN 更新默认订阅并实际访问 HTTPS，出口应为 VPS IP。
4. 设置需要的目标出口数和检测并发，刷新候选并检测，验证进度、手动优先、去重及取消。先使用不限国家且允许 unknown 的技术策略验收；没有画像证据不标家宽。上游供给不足如实等待。
5. VPN Gate 出口可用时验证订阅对应实际 IP、国家命名、外部 SOCKS；停止出口后对应连接失败，本机直出独立可用，不自动回落。
6. 在代理资源测试原始 SSTP；只导出通过且未过期的私有结果。不要求每个国家、候选或固定数量成功。
7. 检查更新：当前最新版应显示无需更新；新正式版发布后可在网页执行完整包更新，重新登录查看完成结果并确认原订阅及设置保留。

全新工作目录、已有系统升级、全新操作系统分别记录；前两项测试不替代用户重装后的最终验收。
