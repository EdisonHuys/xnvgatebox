## 备份内容

本机私有备份目录包含以下文件；具体文件名、源码提交和 SHA256 以目录内 `manifest.json`、`SHA256SUMS` 为准：

| 文件 | 用途 |
| --- | --- |
| `xnvgatebox-source-<提交>.tar.gz` | 当前已提交源码、安装脚本和文档 |
| `xnvgatebox-all-refs.bundle` | Git 提交历史、现有分支与标签，可独立恢复仓库 |
| `v0.6.1-current-private.tar.gz` | 停止本项目后取得的一致完整部署与私有配置 |

| `release-v0.6.1/` | 已核验的正式安装包和官方校验文件副本 |
| `manifest.json`、`SHA256SUMS` | 备份范围、校验结果和摘要 |

服务器归档覆盖本项目程序、固定 Xray、共享工具、`/etc/xnvgatebox`、私有状态和受管服务文件，包括管理路径/密码、订阅口令、客户端身份、第三方代理凭据、Slot 策略和启停意图。它不是整机镜像，不包含 3x-ui 数据库、系统 SSH 主机密钥或所有系统软件包。本轮没有修改 3x-ui 或恢复 Cloudflare。

备份已下载到本机，不依赖即将重置的服务器保存。私有归档含真实凭据，保留在受限目录，不上传 GitHub。归档内容和摘要已检查，Git bundle 另在临时镜像仓库中验证；本轮没有执行整份服务器归档还原演练。

## 安装后直接获取登录信息

重装 Debian 12 amd64 后，先通过可信渠道核对新的 SSH 主机指纹，再以 root 执行 [README 的固定版本一键安装命令](../README.md#debian-12-安装)。该命令最后接上 `xnvgatebox access`，安装成功后直接显示管理地址和初始密码。

首次安装会自动生成独立随机管理路径、密码和订阅凭据。默认管理端口为 8899；浏览器使用命令打印的完整地址登录。没有所有人共用的固定路径或密码，也无需先安装 3x-ui。以后可单独运行 `xnvgatebox access` 再次查看，它不会重置现有凭据；重复安装和在线更新继续保留原值。

重装后的第一轮先不导入旧状态，按 [全新系统验收清单](INSTALL_UPDATE.md#全新系统验收清单) 验证新安装、直出、第三方资源、VPN Gate 和订阅顺序。上游没有合适节点时如实等待，不强求国家或数量；unknown 仍为未知。

## 需要找回旧代码或配置时

可在备份目录检查 `SHA256SUMS`。Git 历史可恢复到新的空目录：

```sh
git clone xnvgatebox-all-refs.bundle xnvgatebox-recovered
```

源码归档可解压到独立目录查看。私有部署归档留作恢复旧设置和凭据之用；先完成全新安装验收，再按需要安排单独恢复，避免把旧状态迁移当成全新系统安装。不要直接把私有配置加入源码仓库，也不要用不匹配版本的程序覆盖现有状态。
