# xnvgatebox VPS 管理器

本目录是本项目的 Linux 管理进程与内置控制台源码。安装、更新及卸载统一使用 [VPS 安装说明](../README.md)；操作步骤见 [首次使用](../../docs/FIRST_USE.md)。

旧版 fanout 的独立安装脚本、f 菜单和服务示例已移除，避免安装到错误目录或使用单文件更新。历史默认路径与实例网络身份的运行兼容仍保留。旧安装的清理方法见 [卸载说明](../../docs/UNINSTALL.md)。
